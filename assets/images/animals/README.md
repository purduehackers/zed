# Anonymous animal avatars

32 unmodified Twemoji SVGs, bundled locally; no third-party image requests.
Artwork by Twitter, Inc. and the Twemoji contributors, licensed CC BY 4.0
(see LICENSE). Source: https://github.com/jdecked/twemoji/tree/b6b55fef1e8636b540a6d016a4729ca8cdf2e60b/assets/svg

The filename describes its animal. `project::anonymous_participant::identity`
maps sandbox replica IDs to matching avatar paths and Anonymous Animal labels.
The avatar border uses that participant's Zed cursor color.
