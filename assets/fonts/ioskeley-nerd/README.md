# IoskeleyMono Nerd Font

Regular, Bold, Italic and Bold Italic copied unmodified from the owner's installed
Nerd Font build of https://github.com/ahatem/IoskeleyMono.
Used for browser buffers (14px, aalt enabled) and the terminal.

SIL Open Font License 1.1; see OFL.txt. Nerd Font glyphs include Powerline and
terminal icons. Faces are bundled because the canvas cannot read system fonts.
