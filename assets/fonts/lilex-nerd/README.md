# Lilex Nerd Font Mono

Four terminal faces from Nerd Fonts v3.5.1, Lilex 2.600 (OFL-1.1).
Source: https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1
Archive: `Lilex.tar.xz`, SHA-256
`34ba9564bcb32c03d2d8e1404e72c5c4320fa99231ba99f4c566a24224f350a3`.
