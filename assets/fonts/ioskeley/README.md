# Ioskeley Mono

Regular, Bold, Italic and Bold Italic copied unmodified from the owner's installed
Ioskeley Mono fonts. Used for browser editor UI at 15px.

Source: https://github.com/ahatem/IoskeleyMono (Iosevka custom build).
SIL Open Font License 1.1; see OFL.txt. The canvas renderer needs bundled TTFs;
fonts installed on the host computer or sandbox are not available to it.
