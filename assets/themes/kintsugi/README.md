# Kintsugi

The owner's unmodified desktop theme, imported from ~/.config/zed/themes/kintsugi.json.
The browser defaults to Kintsugi Dark Flared, with Kintsugi Light Flared available.

Zed port: https://github.com/giacomocavalieri/kintsugi-zed
Original theme: https://github.com/ahatem/vscode-kintsugi
